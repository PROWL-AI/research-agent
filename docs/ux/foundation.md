## 2. Jobs to Be Done
### JTBD-01: Понять и направить работу
- **Statement:** Когда агент работает в цепочке, хочу за минуту понять состояние, результат и расходы, чтобы принять решение без чтения сырых логов.
- **Personas:** P-01
- **Type:** functional
- **Status:** confirmed
- **evidence_kind:** brief
- **decision_status:** accepted
- **validation_status:** unvalidated
- **Forces:** push: непрозрачные логи; pull: одна карточка запроса; anxiety: повторное списание; habit: читать терминал.
- **Success metric:** Оператор находит требующее решения задание и его входные параметры без терминала; продуктовый результат пока не измерен.
