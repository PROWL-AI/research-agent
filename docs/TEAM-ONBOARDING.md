# Prowl Research для команды: как подключиться

Prowl Research в облаке это шлюз для Claude Code к исследованиям и инструментам Prowl. Через него доступны готовые
сценарии исследований (runbooks) и любой инструмент Prowl: поиск, SEO, реклама, отзывы, тренды. Ключи провайдеров
лежат на сервере агента. Вам их не дают и они вам не нужны: у вас свой персональный ключ доступа к агенту.

## 1. Получите ключ

Ключ выдаёт владелец агента. Он присылает его один раз в личном сообщении. Ключ начинается с `prc_`. У ключа есть
права:

| Право | Что можно |
|---|---|
| `read` | смотреть список сценариев, читать результаты своих заданий, запускать бесплатное обучающее задание |
| `research.run` | запускать исследование по сценарию |
| `tools.call` | вызывать один инструмент Prowl |

Ключ личный: не пересылайте его и не кладите в репозиторий, чат или файл проекта. Потеряли или засветили ключ:
скажите владельцу, он отзовёт его и выпустит новый. Ваш старый ключ перестанет работать сразу, ключи других людей
это не затронет.

## 2. Подключите Claude Code

```sh
claude mcp add --transport http prowl-research https://<адрес агента>/mcp \
  --header "Authorization: Bearer <ваш ключ>"
```

Адрес агента пришлёт владелец вместе с ключом. Проверка: в Claude Code выполните `/mcp`, сервер `prowl-research`
должен быть подключён, инструменты `research.*` видны.

## 3. Как работать

- Список сценариев: попросите Claude вызвать `research.list_runbooks`.
- Исследование: `research.run` с названием сценария и входными данными. Один инструмент: `research.tools.call`.
- Ответ приходит заданием: Claude следит за ним через `fabric.job.get`.
- **Лимит зависит от класса ключа.** Ключ человека (класс `interactive`) лимита не имеет: любое задание стартует
  сразу, а траты записываются на ваш ключ. Ключ конвейера или агента по расписанию (класс `automated`) имеет дневной
  лимит, 10 USD за сутки UTC, если владелец не назначил больше: задание, которое укладывается в остаток лимита,
  стартует сразу, остальные ждут одобрения владельца. Учебное задание (`research.tutorial`) бесплатное и стартует
  всегда.
- Вы видите только свои задания. Чужие задания вам не видны, и ваши не видны другим.

## Если не работает

| Что видите | Что это значит |
|---|---|
| `401` при подключении | ключ неверный или отозван; попросите новый |
| `scope-not-granted` | у ключа нет права на этот инструмент; попросите владельца выпустить ключ с нужным правом |
| задание долго в ожидании | у ключа класса `automated` исчерпан дневной лимит, задание ждёт одобрения владельца; у ключа `interactive` задания не ждут, сообщите владельцу |
| `degraded` в ответе | у сервера не подключён ключ провайдера; сообщите владельцу |
