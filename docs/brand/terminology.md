# Терминология

- **Prowl Research** — этот отдельный агент и его панель. Не встроенный Prowl Agent основного продукта.
- **Запрос** — одна долговечная задача сервиса (Fabric job).
- **Шаг** — один вызов инструмента или модели.
- **Цепочка** — внешняя последовательность, которой управляет Fabric; локальное поле цепочки передано вызывающим агентом и само по себе не доказывает binding.
- **Подтверждённые расходы** — цена из ответа провайдера. Не оценка.
- **Учебный пример** — синтетические данные, исключённые из настоящих расходов.
- **Нужно решение** — выполнение ещё не началось и ждёт выбора оператора.
