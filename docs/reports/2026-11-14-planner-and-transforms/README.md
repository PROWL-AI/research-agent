## B-129: планирование без рассуждения

Один план на каждую пару, `moonshotai/kimi-k3.1-pro`, одинаковые входы, код 0.6.13.

| Ранбук | С рассуждением: секунды, шаги инструментов, разных инструментов | Без рассуждения |
|---|---|---|
| domain-baseline | 508, 63, 52 | 74, 61, 55 |
| competitor-seo | 420, 102, 44 | 165, 98, 44 |
| saas-competitor-teardown | 743, 88, 41 | 69, 83, 39 |

Выходных токенов без рассуждения в 4 до 6 раз меньше (29195 против 4971 на domain-baseline). Решение: без
рассуждения по умолчанию; `RESEARCH_PLANNER_REASONING=on` возвращает поведение 0.6.13. n=1 на пару: качество плана
сравнено по покрытию инструментов, не по отчёту.

## B-132: источники трансформа

Переигровка `select_competitors` на сохранённых артефактах прогона, по три раза каждым кодом.

| | Читал источников из названных | Входных токенов | Привязок принято |
|---|---|---|---|
| 0.6.13 | 3 из 4 (главная страница не попала, `dfs_competitors` обрезан до самого домена) | 3457 до 3497 | 0, 0, 0 |
| 0.6.14 | 4 из 4, компактный JSON | 8785 до 8813 | 0, 0, 0 |

Новый код видит все источники и отвергает кандидатов по существу: `exa_similar` вернул государственные сайты,
`spyfu_competitors` утилиты бэклинков, `dfs_competitors` площадки (YouTube, Reddit). Для prowl.chat поиск
конкурентов Prowl не нашёл ни одного в нише; это данные, а не дефект агента.

## B-131: аудит сайта в domain-baseline

В 1.1 был `seo_growth_audit` (принимает только сырой HTML), но не было инструмента, отдающего HTML, и шаг не
говорил передать `{{output:...}}`: аудит не мог выполниться ни в одном прогоне. 1.2 добавляет
`firecrawl_scrape_page_seo` и передаёт его ответ; 1.1 остаётся в `versions/1.1.md` (R28).
